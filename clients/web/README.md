# Web Portal - Remote Jackfruit Monitoring & Outbreak Map (Next.js)

Nền tảng Web giám sát dịch tễ sâu bệnh từ xa và kết nối dữ liệu từ các nông hộ.
Tương ứng trực tiếp với:
- **Task 7.1**: Development of a web application for real-time monitoring of regional pest and disease situations.
- **Task 7.2**: Data connectivity support from individual farming households or jackfruit orchards to the IoT system.

## Hướng dẫn cài đặt & chạy thử
```bash
cd clients/web
npm install
npm run dev
```
Truy cập giao diện tại: `http://localhost:3000`
