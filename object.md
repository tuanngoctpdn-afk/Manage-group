15.1. Research Contents
Objective 1: Study of common pests and diseases on jackfruit trees and fruits in Vietnam
Task 1.1: Field survey and data collection on major harmful pests and diseases.
Task 1.2: Symptom analysis on leaves, stems, and jackfruit fruits to establish identification criteria.
Objective 2: Construction and development of a dedicated image dataset of jackfruit pests and diseases
Task 2.1: Collection and annotation of pest and disease images on jackfruit trees across developmental growth stages.
Task 2.2: Standardization of image data formats for AI model training.
Objective 3: Research and application of Machine Learning and Deep Learning techniques in pest and disease detection and recognition
Task 3.1: Comparative performance evaluation of deep learning models (CNN, YOLO, EfficientNet, etc.).
Task 3.2: Proposal of an optimized model for early pest and disease detection on jackfruit trees.
Objective 4: Design of data analysis and evaluation solutions on edge and cloud computing platforms
Task 4.1: Implementation of the data ingestion pipeline from IoT devices (cameras, environmental sensors).
Task 4.2: Real-time data analysis on edge devices and synchronization with the cloud platform.
Objective 5: Development of pest and disease recognition software running on mobile devices (Android/iOS)
Task 5.1: User-friendly UI/UX design supporting direct camera scanning on mobile phones.
Task 5.2: Integration of the recognition model with real-time diagnostic feedback for users.
Objective 6: Construction of a smart agricultural recommendation support system for jackfruit trees in Vietnam
Task 6.1: Provision of pest and disease treatment recommendations based on recognition results, weather, and environmental data.
Task 6.2: Support for jackfruit quality classification during the harvest stage based on imagery.
Objective 7: Development of a remote pest and disease observation and monitoring system via a web platform
Task 7.1: Development of a web application for real-time monitoring of regional pest and disease situations.
Task 7.2: Data connectivity support from individual farming households or jackfruit orchards to the IoT system.
